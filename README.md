# 拾页 · 本地小说阅读器

拾页是一个装在自己电脑上的看小说工具：不注册账号、不装 App、也没有广告弹窗。

它读的是网上连载的小说——玄幻、都市、种田、无限流这类网文，以及日系轻小说（《无职转生》《Re:从零开始》那种）。输入书名就能搜，点进去从第一章开始读，读到哪儿它都记着。

书架、阅读进度和阅读偏好都只存在你自己的硬盘里，不上传、不同步。想换台电脑，把文件夹拷过去就行。

## 能干什么

**搜书** — 一个书名同时查几个来源，谁有就列谁，封面、作者、简介一起出来。

**发现** — 不知道读什么的时候，按分类和榜单翻一翻，像逛书店那样找。

**书架** — 点一下收进来，下次打开直接接着上次那页，不用重新找。

**读起来顺手** — 左右方向键翻章，点屏幕两边也能翻；字号、行距、页面宽度、背景色（浅色／护眼／深色）都能自己调，调完会记住。

**缺章自动换源** — 当前来源缺了某一章，它会去别的来源找同一章接着读，读完再切回来。

## 怎么跑

需要 Node.js 18 以上；走浏览器的那几个来源需要 24 以上。

```powershell
npm install
npm start
```

浏览器打开 http://127.0.0.1:3000 就能用。服务只监听本机，同一个局域网里的其他设备访问不到。

## 桌面版

不想每次开命令行的话，可以打包成单独的程序：

```powershell
npm run desktop        # 直接运行
npm run desktop:pack   # 打包成 dist/Shiye-1.0.0-portable.exe
```

生成的 exe 双击就能用，它会自己起一个本地服务（3000–3009 里挑一个空闲端口），关窗就退出。

## 关于书源

`sources/` 里是几个 JSON 文件，描述「去哪个地址、用哪个选择器取书名／目录／正文」。想加新来源照着改一份，重启生效。

规则只描述页面结构，不包含书籍内容，也不附带来源推荐。

## 实现说明

给想改代码的人：

- 单进程 Node 服务 + 原生前端，运行时依赖只有 cheerio
- 搜索并发查询各来源，单个来源失败不影响其他来源；结果缓存 1 分钟缓解限流
- 请求超时 15 秒、失败重试一次，按 Content-Type 解码（含 GBK）
- 需要通过站点验证的来源，借本地 Edge／Chrome 的 CDP 完成，无头模式启动，空闲 60 秒回收，临时用户目录与日常浏览器隔离
- 接口：`/api/sources`、`/api/search`、`/api/book`、`/api/chapter`、`/api/image`
- 桌面版基于 Electron，启用单实例、contextIsolation、sandbox，关闭 nodeIntegration
